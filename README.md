# Library Management System – BPMN Models

## 📘 Overview

This repository contains a comprehensive Business Process Model and Notation (BPMN) document detailing the core processes of a Library Management System. The `BPE project.pdf` outlines and visualizes the following key workflows:

* **Registration Process**: Steps involved in registering a new patron.
* **Book Borrowing Process**: Procedures for borrowing books from the library.
* **Cataloging and Classification Process**: Methods for organizing and classifying library materials.

## 📄 Document Details

* **File**: [BPE project.pdf](https://github.com/anum-349/Library-Management-System-BPMN/blob/main/BPE%20project.pdf)
* **Content Includes**:

  * Descriptions of each process.
  * Visual BPMN diagrams illustrating workflows.
  * Exception handling models for each process.

## 📂 Repository Structure

* `BPE project.pdf`: The main document containing all BPMN models and descriptions.
